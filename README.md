# Портфолио — Саят

Сайт-портфолио «Обо мне», свёрстанный вручную на HTML, CSS и JavaScript. Мультистраничная структура — каждый раздел на отдельной странице.

## Технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, медиазапросы, CSS-анимации)
- Vanilla JavaScript (IntersectionObserver, бургер-меню, skill-bars)
- Google Fonts: Unbounded + Inter

## Структура проекта

```
portfolio/
├── index.html      — главная + сетка разделов
├── about.html      — 01. О себе
├── goal.html       — 02. Моя цель
├── story.html      — 03. Как я пришёл в IT
├── mentor.html     — 04. Мой ментор
├── progress.html   — 05. Точка А → Точка Б
├── hobbies.html    — 06. Хобби и интересы
├── works.html      — 07. Мои лучшие работы
├── github.html     — 08. GitHub
├── style.css       — все стили
├── script.js       — весь интерактив (один файл для всех страниц)
└── README.md
```
